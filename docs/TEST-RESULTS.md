## ما كُتب ولم يُشغَّل هنا — ولماذا

**بيئة العمل تمنع الوصول إلى مستودع Maven Central** (رفض 403 من وكيل الشبكة)، لذلك لم يمكن تنزيل مكتبات Spring Boot وتشغيل:

- `mvn verify` للخادم: `FaceMatcherTest` (6)، `BiometricCryptoTest` (4)، `ValidationUtilsTest` (2)، و`AttendanceFlowIntegrationTest` (12 سيناريو على PostgreSQL حقيقي: الدخول والقفل، فرض تغيير كلمة المرور، الرموز المزوّرة، مصفوفة الصلاحيات كاملة، قواعد تسجيل الوجه والموافقة وتكرار الهوية، الدورة الكاملة كاميرا ← يدوي ← إغلاق ← اعتماد ← تقرير ← تصدير PDF/Excel، سجل العمليات، تعطل خدمة الوجوه، رفض الملفات غير الصورية، أخطاء التحقق لكل حقل).
- التشغيل الكامل من البداية للنهاية (واجهة ← خادم ← خدمة وجوه ← قاعدة بيانات).
- `docker compose up` (لا يوجد Docker daemon في البيئة)، وفحص إعداد Nginx.

**هذه الاختبارات جاهزة وتعمل تلقائياً** عبر `.github/workflows/ci.yml` عند رفع المشروع إلى GitHub، أو محلياً:
```bash
cd backend && TEST_DB_URL=jdbc:postgresql://localhost:5432/attendance_test mvn verify
```
إذا ظهر خطأ ترجمة عند أول تشغيل، فالمرجّح أنه بسيط (استيراد أو توقيع دالة)، لأن الكود كُتب دون أن يُترجم مع مكتباته هنا.

- نسب TAR/FAR الفعلية (الهدف 95% / 1%) على صور جنود الوحدة بالزي والخوذ وفي إضاءة الساحة.
- زمن المعالجة على السيرفر المستهدف (8 أنوية).
- الكاميرا على هواتف حقيقية عبر HTTPS.
